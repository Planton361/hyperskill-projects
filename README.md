# Hyperskill Projects

A collection of my completed Hyperskill projects, organized by programming
language. Each project is exported as a standalone application that can be built
and run independently.

## Projects

| Project | Language | Topics |
|---------|----------|--------|
| [Simple Chat Bot with Java](java/Simple%20Chat%20Bot%20with%20Java/) | Java | Console input/output, methods, loops, conditionals, basic arithmetic |

## Repository Structure

```text
hyperskill-projects/
├── java/
│   └── Simple Chat Bot with Java/
└── scripts/
```

## Running a Project

```bash
cd "java/Simple Chat Bot with Java"
./gradlew run
./gradlew build
```

## About the Export Process

Projects are exported from their Hyperskill workspaces as standalone projects.
Hyperskill metadata, IDE files, platform tests, and build artifacts are excluded.

## Tooling

Local import tools and their documentation are in [`scripts/`](scripts/).
