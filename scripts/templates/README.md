# Retained build templates

The Java Gradle templates and verified wrapper are retained for reference and
for earlier schema-2 exports. The current publisher does not consume, export,
or run them. New Hyperskill exports are source-only archives and need no
Java/Gradle installation.

Academy build files remain untrusted input and never configure an export. The
legacy template checksums are preserved for validating historical build
artifacts; they are not an acceptance criterion for new project archives.
