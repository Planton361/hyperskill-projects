# Adaptive dual view — current decision

Production migration is **PAUSED_PENDING_ADAPTIVE_VIEW_ACCEPTANCE**.
The strict Version-A Production migration is **NOT CURRENTLY APPROVED FOR EXECUTION**.
All previously prepared strict-global migration packages are non-applicable.
No historical report, package, token, seal or receipt supersedes this decision.
The normal updater rejects that operation before loading any historical operator;
the real spatial authorization entry point also rejects direct execution.

Knowledge identity, immutable global reference geometry and derived local
presentation geometry are three distinct contracts. The same semantic registry
serves every view. My Knowledge defaults to explicitly learned Topics plus
structural ancestors; ACTIVE_HISTORY is separately named Accepted Landscape.
Global reference order and primary-parent metadata guide compact local layout,
while global and local absolute coordinates are stored separately.

The integration candidate is generated by the normal Knowledge loader and Catalog
projection into `docs/knowledge-map-adaptive-preview/`. It does not pass through
the legacy persistent-slot allocator, migration review or Production transaction.
Global reference bytes are packaged unchanged. Local geometry, separate cameras,
collapse state and prior animation positions exist only in browser memory.
No personal geometry checkpoint is needed for the deterministic initial version.

Historical prototypes and validations remain evidence. Production, State and
Knowledge are not modified by this preview command:

```sh
python -B scripts/update-knowledge-atlas.py --adaptive-preview --json
python -B scripts/update-knowledge-atlas.py --adaptive-preview --check --json
```

Further acceptance may authorize a future **adaptive-view migration preview**;
it never implicitly authorizes an old strict-global migration.
