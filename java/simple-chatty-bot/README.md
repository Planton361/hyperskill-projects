# Simple Chatty Bot

Sprache: Java 23

Konzepte: Konsolenein-/ausgabe mit Scanner, Methoden, Schleifen, Verzweigungen und modulare Arithmetik

Build: `./gradlew build`

Start: `./gradlew run`

Voraussetzung: JDK 23 oder neuer für Gradle; Java-Zielversion 23.
