# Simple Chat Bot with Java

A small interactive console bot that greets the user, estimates an age from
remainders, counts, and asks a programming question.

## Topics

- Console input/output
- Methods
- Loops
- Conditional logic
- Basic arithmetic

## Requirements

- JDK 23

## Run

```bash
./gradlew run
```

Build with `./gradlew build`.
