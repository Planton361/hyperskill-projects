# Java project archives

New Java exports contain the final Academy solution sources under `src/`, a
short README, and a SHA-256 manifest. They are source archives; no compiler,
Java version, build system, framework, or runtime is required to accept them.

Legacy examples (retained unchanged):

| Project | Format |

All Java archive folders in this directory are authoritative, including new
source-only projects. This README is not an exhaustive manually maintained
project list; see the [live MyAtlas portfolio](https://planton361.github.io/myatlas/knowledge-map/?view=skill-tree)
for current totals. Future projects use the [source-only publisher](../scripts/README.md).
Both schemas remain accepted by MyAtlas.
